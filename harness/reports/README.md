# Reports

This folder contains the **synthesised reports** the harness produces.

| File                                      | Purpose                                                |
|-------------------------------------------|--------------------------------------------------------|
| `traceability.md`                         | REQ → FEAT → SCN → TC → RUN → evidence                |
| `coverage.md`                             | Requirement / feature / API / UI / DB coverage        |
| `test-summary.md`                         | Latest run summary                                     |
| `regression-report.md`                    | Last regression run                                    |
| `release-readiness.md`                    | Go / no-go for a release                                |
